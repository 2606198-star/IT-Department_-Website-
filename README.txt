DEPARTMENT OF INFORMATION TECHNOLOGY WEBSITE

Files:
- index.html       = Home page
- courses.html     = Courses page
- contact.html     = Contact page
- style.css        = Website styling
- it-laboratory.png = IT laboratory image

GitHub Pages:
1. Create a GitHub repository.
2. Upload all five files into the repository.
3. Open Settings > Pages.
4. Under Build and deployment, choose Deploy from a branch.
5. Select the main branch and the / (root) folder, then Save.
6. Wait for GitHub to publish the site.
7. Copy the GitHub Pages URL and test it in a private/incognito browser.
8. Put the working URL into the Word/PDF submission document.

IMPORTANT:
Do not delete or rename index.html because it is the home page.
